# مواصفة UX — نظام محل المراتب (v1 مسودة)

> العربية أولاً (RTL)، الإنجليزية ثانياً. الموبايل أولاً للعملاء والمندوبين، الديسكتوب أولاً للكاشير والداشبورد.

## 1. مبادئ عامة

1. **3 نقرات للشراء**: تصفح → منتج → دفع. أي خطوة زيادة لازم مبرر.
2. **السرعة = فلوس**: صفحات المتجر LCP أقل من 2.5 ثانية؛ شاشة الكاشير تعمل offline-first للبحث والسكان.
3. **لا مفاجآت في السعر**: الخصم والهدية والشحن ظاهرين قبل زر الدفع (price-preview).
4. **الصور تحسم**: كل منتج صور متعددة + مقاسات مرسومة؛ المرتبة تُعرض بغرفة نوم حقيقية مش خلفية بيضاء فقط.
5. **الثقة**: تقييمات موثقة + ضمان واضح بالسنوات + سياسة استرجاع ظاهرة في صفحة المنتج.

## 2. المتجر (عميل)

- **الرئيسية**: بحث بارز + أقسام (مراتب/مخدات/كفرات) + الأكثر مبيعاً + اختبار "لاقي مرتبتك" + عروض البندل.
- **التصفح والفلاتر**: خامة، صلابة، مقاس، ارتفاع، براند، سعر، تقييم 4+. الفلاتر من صفات EAV نفسها (أي صفة جديدة تظهر تلقائياً).
- **صفحة المنتج**: صور، السعر قبل/بعد الخصم، اختيار المقاس (يغيّر السعر والSKU)، التوفر (متاح/كمية محدودة)، زر "أضف للسلة" ثابت أسفل الشاشة على الموبايل، تبويبات (المواصفات/الضمان/التقييمات/التوصيل)، "اشترى معه" (كفر متوافق).
- **الاختبار Quiz**: 5–7 أسئلة، شريط تقدم، سؤال واحد في الشاشة، تخطي مسموح، النتيجة: 3 ترشيحات بنسبة توافق + "ليه دي؟" (شرح الأسباب يبني الثقة) + زر مقارنة.
- **السلة والدفع**: سلة منزلقة (drawer) بدون مغادرة الصفحة؛ الدفع: بيانات → شحن → دفع → تأكيد برقم تتبع. الضيوف يشتروا بدون حساب (برقم الموبايل) مع خيار إنشاء حساب بعد الشراء.
- **التتبع**: صفحة برقم الطلب + خط زمني (تأكيد → تجهيز → شحن → تسليم) + إشعار SMS/واتساب عند كل مرحلة.
- **الحساب (Portal)**: طلباتي، عناويني، الضمان (تسجيل بالسيريال + حالة المطالبة)، المفضلة، تقييماتي.
- **المراجعات**: تقييم بالنجوم + نص + "اشتريتها فعلاً" شارة؛ الفرز (الأحدث/الأعلى/الأكثر فائدة).

## 3. الكاشير POS (سرعة فوق كل شيء)

- شاشة مقسمة: بحث/سكان يمين، الفاتورة الحالية شمال، الإجمالي ضخم وواضح.
- السكان بالباركود أو كتابة SKU (منتجات بلا باركود تُباع عادي بالبحث).
- خصم سريع: زر خصم % أو مبلغ على سطر أو الفاتورة + بندل بضغطة + هدية تُضاف سطر صفر.
- الدفع: كاش/شبكة/تقسيط (يُحدد لاحقاً) + طباعة فاتورة + فتح الدرج تلقائياً.
- الشفت: فتح (رصيد بداية) → مبيعات → إسقاط نقدية → إغلاق (فرق مُعلن).

## 4. الداشبورد (إدارة)

- **نظرة عامة**: مبيعات اليوم/الأسبوع، الطلبات المعلقة، النواقص الحرجة، مطالبات مفتوحة — كروت + تنبيهات بألوان.
- **التحليلات**: إيراد/ربح، سرعة المنتجات، موسمية، خريطة محافظات، أداء فروع ومناديب — فلاتر زمنية موحدة.
- **إدارة الكتالوج**: إنشاء صنف/صفة/بريسِت بمعالج خطوات + quick-create المنتج (قالب + مقاس واحد).
- كل جدول: بحث + فلترة + تصدير Excel (المرتبات والتقارير أولاً).

## 5. المخزن (أمين المخزن — موبايل/تابلت)

- أزرار كبيرة، سكانر أولاً: بحث بالباركود/SKU → الكمية والمكان.
- استلام تحويل: قائمة معلقة → تأكيد بكميات فعلية + تسجيل توالف بالصور.
- الجرد: عدّ بالسكان، الفرق يُعرض فوراً، التسوية للمدير فقط.

## 6. التوصيل (سائق — موبايل)

- رحلتي اليوم كقائمة محطات مرتبة + خرائط + اتصال بالعميل بضغطة.
- تسليم: توقيع/صورة إثبات؛ فشل: سبب من قائمة + إعادة جدولة.

## 7. الموظف (Self-service)

- حضور: زرار دخول/خروج واحد + سجل شهري؛ إجازة: طلب بسبب وتواريخ + حالة الطلب؛ مرتبي: قسائم + عمولاتي.

## 8.  وتفاصيل

- تباين ألوان، خط عربي واضح وكبير للأسعار، دعم قارئ الشاشة للمتجر، رسائل خطأ بالعربية الفصحى المبسطة مع حل ("المقاس ده خلص — جرّب 160×195").
- العملة EGP بصيغة مصرية (ج.م 10,500)؛ الأرقام: عربية أم لاتينية؟ (سؤال أدناه).

## 9. قرارات محسومة (من النقاش)

1. **الدفع**: خليط يدوي في الإطلاق — كاش عند الاستلام + تحويل/محفظة بتأكيد يدوي من الإدارة. بوابات الدفع الإلكتروني تُؤجل لمرحلة لاحقة.
2. **الضيوف**: الشراء بدون حساب مسموح (برقم الموبايل) + عرض إنشاء حساب بعد الشراء.
3. **الأرقام**: لاتينية (123) مع ج.م في كل الواجهات.
4. **المراجعات**: المشترون فعلاً فقط (شارة "اشتريتها فعلاً").
