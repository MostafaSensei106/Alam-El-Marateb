# تخطيط موديول العملاء CRM (v2 — تفصيلي)

> **الحالة: مُنفذ ومُختبر** (بروفايل + عناوين + مفضلة + ضمان شهادة + مطالبات + `CrmFlowTest` أخضر).
> P5. العملاء، الضمان بالشهادة، المطالبات، والمتابعة.

## 1. بيانات العميل

- `customer_profiles` امتداد لـ `users`: المحافظة/المدينة، الشريحة (جديد/متكرر/VIP)، مصدر المعرفة، تاريخ الميلاد (لعروض — nice).
- `customer_addresses`: عدة عناوين + افتراضي + لوكيشن (nice: pin على الخريطة).
- الضيوف (guest_phone) يترقّون لحساب كامل عند تكرار الشراء (اقتراح تلقائي).

## 2. الضمان (قرار: شهادة لكل فاتورة — لا سيريال لكل قطعة)

- `warranties`: شهادة مرتبطة بالفاتورة (`invoice_id`) + تغطية حتى تاريخ + حالة.
- العميل يسجل/يتحقق من البورتال (`/portal/warranties`)؛ الإدارة تدير (`/crm/warranties`).
- تنبيه تلقائي: ضمان يقترب من الانتهاء → فرصة بيع جديد (follow-up).

## 3. المطالبات

`warranty_claims`: (بلاغ → معاينة مجدولة → إصلاح/استبدال → إغلاق) + صور + سبب + قرار.
SLA لكل مرحلة يظهر في الداشبورد (مطالبات متأخرة تنبيه أحمر).

## 4. المتابعة

- حجوزات بميعاد، عربونات معلقة، مطالبات مفتوحة، عملاء VIP بلا شراء منذ X.
- الرد عبر واتساب/SMS من سجل العميل (تكامل لاحق — nice).

## 5. Must / Nice

**Must**: profiles + عناوين + سيريال + مطالبات + SLA.
**Nice**: شرائح تلقائية RFM، نقاط ولاء، عروض أعياد الميلاد، واتساب مدمج.

## 6. قرارات محسومة (من النقاش)

1. **الضمان**: شهادة واحدة لكل فاتورة (لا سيريال لكل قطعة).
2. **المعاينة**: مجانية دائماً.
