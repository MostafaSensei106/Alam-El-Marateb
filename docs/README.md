# docs — تخطيط نظام إدارة محل المراتب

كل التخطيط هنا. مفيش تنفيذ من غير بند مكتوب هنا الأول.

## الهيكل

- [`arch.md`](arch.md) — الوثيقة الأم: المعمارية، الموديولز، الداتابيز، المراحل P0→P7.
- [`database.md`](database.md) — تصميم قاعدة البيانات التفصيلي: كل جدول بأعمدته وقيوده وخريطة الكود.
- [`api.md`](api.md) — كتالوج الـ endpoints: الميثود + المسار + الدور + الحالة (موجود/مخطط/يُحذف).
- [`api-status.md`](api-status.md) — سياسة HTTP الملزمة: الميثودز والأكواد الدقيقة لكل حالات النجاح والفشل.
- [`api/postman_collection.json`](api/postman_collection.json) — مجموعة Postman (إلزامي تحديثها مع كل موديول جديد).
- [`ux.md`](ux.md) — مواصفة تجربة الاستخدام لكل جمهور + القرارات المحسومة.
- `modules/` — ملف تخطيط لكل موديول (`catalog.md`, `sales.md`, ...) يُكتب قبل تنفيذ مرحلته.
- `decisions/` — قرارات معمارية مسجلة (ADR مختصر: السياق → القرار → البدائل المرفوضة).
- `api/` — عقود الـ endpoints لكل مرحلة قبل كتابة الكنترولرز.

## القواعد

1. أي مرحلة (P1...) تبدأ بملفها في `modules/` أولاً.
2. أي قرار معماري جديد يتسجل في `decisions/` بتاريخه.
3. `arch.md` مرجع عام فقط — التفاصيل في ملفات الموديولز.
