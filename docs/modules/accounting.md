# تخطيط موديول المحاسبة accounting (v1 — مسودة)

> P6. شجرة حسابات، قيود تلقائية، خزن، مصاريف، شيكات، تقارير.

## 1. شجرة الحسابات

`chart_of_accounts`: أصول/خصوم/إيرادات/مصروفات + مراكز تكلفة = الفروع. شجرة جاهزة seed + حسابات الموردين والعملاء الآجل.

## 2. القيود التلقائية (لا قيد يدوي للعمليات)

- البيع: إيراد + مخزون/تكلفة + خزينة/عميل آجل.
- الشراء والاستلام: مخزون + مورد.
- المرتبات المعتمدة: مصروف + مستحق.
- القيود اليدوية للمحاسب فقط (تسويات) بصلاحية منفصلة.

## 3. الخزن والنقدية

`treasuries` (خزنة كل فرع + رئيسية)، تحويلات بينها، إسقاطات شفتات الكاشير تُطابق تلقائياً، عجز/زيادة بمعالجة معتمدة.

## 4. المصاريف والشيكات والآجل

`expenses` (بند + فرع + مرفق صورة)، `checks` (صادر/وارد + حالة: محفظة/مقدم/مرفوض)، عملاء آجل وموردين بحدود ائتمانية (سؤال أدناه).

## 5. التقارير

ربح/خسارة، ميزانية، ضريبة (VAT؟ — سؤال أدناه)، كشف حساب عميل/مورد، يومية الخزنة.

## 6. Must / Nice

**Must**: الشجرة + قيود تلقائية + خزن + مصاريف + تقارير أساسية + Excel.
**Nice**: شيكات إلكترونية، موازنة تقديرية، أصول ثابتة وإهلاك.

## 7. قرارات محسومة (من النقاش)

1. **البيع الآجل**: ممنوع — كاش/شبكة/تحويل/تقسيط داخلي فقط.
2. **الضريبة**: الأسعار شاملة VAT ولا يظهر بند منفصل في الفاتورة.
